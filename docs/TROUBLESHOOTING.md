# 故障排查

## 双击脚本后没有网页

先看窗口是否显示“已启动”。start.bat 会在依赖通过后自动打开默认浏览器，必须保持窗口打开。服务端手动地址是 http://localhost:8000/admin，客户端是 http://localhost:8765/client。

没有浏览器或远端无图形桌面时不会自动出现本地窗口。服务端可从另一台电脑访问其服务器 IP/域名，但必须用 `--host 0.0.0.0` 或 Windows `-BindAddress 0.0.0.0` 对外监听。客户端只允许在所在设备的浏览器访问。

Linux 文件叫 start.sh，Windows 文件叫 start.bat，不是 start.bash。用 `sh start.sh` 运行即可，不需要先修改可执行权限。

## 找不到 Python / 版本不合格

先运行 setup.bat 或 `sh setup.sh`。启动器会检查版本及 SQLite/SSL，再通过支持的包管理器尝试安装。查看输出的实际解释器路径，避免误用了旧 Python 或 Windows Store 占位命令。

WinGet 不存在时安装 Microsoft App Installer，或手动安装 Python 3.10+；Linux 没有 root/sudo、软件源失败、包管理锁或旧发行版只提供旧 Python 时需要设备管理员处理。可设置 EDU_PYTHON 指向完整解释器路径，不要把参数写入该变量。

离线且缺少运行环境无法凭空安装；先联网完成配置或由管理员提前安装依赖。不要为了通过自检删除系统 Python、关闭证书校验或覆盖系统软链接。

只检查而不安装：Windows `start.bat -CheckOnly`；Linux `sh start.sh --check-only`。不允许启动时安装：使用 `-NoInstall` / `--no-install`。详细行为见 [环境说明](ENVIRONMENT.md)。

## 端口占用 / 网页提示无法访问

关闭之前重复启动的服务窗口，重新运行。服务端在成功绑定端口后才显示已启动。自定义端口示例：Windows `start.bat -Port 8080`，Linux `sh start.sh -- --port 8080`。服务端改端口后也要更新客户端远端地址；客户端改端口会切换浏览器本地数据空间，先导出设备备份。

代理或 VPN 可能干扰 localhost，检查是否允许本机地址直连。服务端自动打开前的内部就绪检查会绕过代理，客户端远端 HTTPS 证书仍正常校验。不要直接关闭所有浏览器安全功能来解决连接问题。

## 启动没有显示管理员密码

仅创建管理员时显示一次随机密码；已有数据库只显示用户名和重置提示。默认用户名 admin。DEMO_ADMIN_PASSWORD 仅首次创建时有效，不会每次覆盖已有密码。

Windows 双击 reset_admin.bat；Linux 执行 `sh reset_admin.sh`。输入两次至少 8 字符的新密码，输入时不显示字符。默认使用服务端 data/learning.db 或 EDU_DATA_DIR。不要删除数据库：用户、课程、授权本来可以全部保留。

Docker 用户在容器里执行 `python reset_admin.py`，避免重置宿主机另一个数据库。具体命令见部署文档。

## Chrome 提示密码遭泄露

这是浏览器对已知泄露凭据的提醒，不能单凭此提示认定 Demo 数据库已泄露。使用重置工具设置全新、未在其他网站复用的随机密码，并更新浏览器为 localhost 保存的旧密码。不要把密码发到聊天或关闭提醒代替更换密码。可参考 [Google 说明](https://support.google.com/chrome/answer/10311524?hl=zh-Hans)。

## 客户端无法连接或没有课程

填写远端最终根地址，例如 https://learn.example.com，不带 /admin。远端不是客户端本机的 8765 地址。确认服务端正在运行、对外监听及防火墙放行。HTTPS 证书必须有效；网关不跟随重定向，填写跳转后的最终地址。

学生注册默认没有课程。管理员在“用户与访问权限”授权后，学生重新登录。权限修改会使更新会话失效；本地已下载课程仍能继续用。切换服务器地址也需要重新登录。

## 离线重开失败 / 更新后界面还是旧的

正常情况下保持本地客户端程序运行即可，无需云端。只有在“离线页面已就绪”后，才支持本地程序也停止时重新打开缓存页。首次未缓存或清理网站数据后仍需本地程序提供页面。

始终使用原浏览器、原地址和端口。localhost 与 127.0.0.1 不共享存储。页面更新可能受 Service Worker 旧缓存影响，重新加载或在开发者工具更新 Worker；发布者应递增缓存版本。操作前先导出数据，不要直接点击清除全部网站数据。

## 学习记录不见了 / 无法保存

确认本地学习者、浏览器、地址、端口和筛选条件。更换这些内容不会自动迁移数据。代码目录不包含浏览器记录；使用完整设备备份迁移，单独 CSV/记录 JSON 不能导入恢复。

本地存储可能因无痕模式、网站数据清理、空间不足或策略禁用而不可用。系统保存失败会提示，不会假装成功。先导出数据，再按学习者清理不需要的记录。导入会覆盖目标设备全量数据，先备份目标设备。

## 没有英语声音 / 读卡没有反应

安装操作系统本地英语语音包，重新打开浏览器，检查输出设备、音量并实际试听。启动脚本不保证安装语音包。没有本地语音时，文字与拼写仍可用；失败或中断的语音不记为完成。

USB 读卡器需为键盘输入模式，RFID 输入框有焦点并在读卡后发送 Enter；UID 格式需与绑定一致。SPI/GPIO 读卡器不能直接作为键盘使用，当前未提供相应驱动。
